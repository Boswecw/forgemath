# ForgeMath repository authority

ForgeMath is the Forge ecosystem's backend authority for governed, deterministic math and rule evaluation. It owns versioned governance registries, canonical evaluation and lifecycle truth, runtime admission evidence, bounded execution, projections, an Evaluation Spine CLI, and optional ForgeLineage emission. It is not a general-purpose expression or symbolic-algebra engine.

## Authority and documentation

- `doc/system/` contains the authored canonical system-reference sources.
- `doc/MATSYSTEM.md` is generated by `bash doc/system/BUILD.sh`; never edit it directly.
- `AGENTS.md` governs repository work. `CLAUDE.md` is the Claude-specific concise companion and may not contradict this file, code, migrations, tests, or `doc/MATSYSTEM.md`.
- `README.md` is an operator entry point. Files under `docs/` are design references or historical context, not canonical current-state authority.

## Mathematical and truth boundaries

- The only canonical FastAPI execution lanes currently registered are `verification_burden`, `recurrence_pressure`, and `exposure_factor` in `app/services/execution_service.py`.
- Do not add lanes or change formulas, weights, thresholds, rounding, quantization, normalization, or golden-vector semantics without separately authorized governance approval.
- Do not introduce arbitrary expression evaluation. Governed code and typed contracts, not caller-supplied expressions, define executable math.
- Canonical numeric artifacts use deterministic `Decimal` computation and persist as canonical decimal strings. Never route canonical math through binary floats.
- `POST /lane-evaluations` is manual ingest for non-computed historical/audit truth only. Computed canonical truth enters through `POST /lane-executions` and the governed execution service.
- Persisted governed payloads are append-only. Only declared lifecycle-closure fields may change; supersession preserves history and lineage.
- Missing, inactive, incompatible, non-deterministic, or cross-lane bindings fail closed. Read models and projections are never source truth.

## Runtime surfaces and integrations

- The FastAPI service owns registry, evaluation, lifecycle, admission, projection, and bounded lane-execution routes.
- `python -m app.evaluation_spine_cli` is a distinct file-in/file-out Evaluation Spine authority surface; it is not the FastAPI execution route.
- Evaluation Spine lineage emission is default-off. When `FORGEMATH_LINEAGE_URL` is configured, ForgeMath can emit its own nodes and consumed edge to DataForge-Local through the pinned ForgeLineage SDK; failures remain non-blocking for the file evaluation.
- Forge_Command consumes `python -m app.health_cli` as a lightweight producer probe and may resolve the emitted output contract artifact during its gate walk. Do not modify Forge_Command here.
- The lightweight health command checks only the Evaluation Spine CLI import surface. `python -m app.health_cli --readiness` explicitly checks local configuration, an existing database connection, migration-head alignment, FastAPI construction, lane registration, and optional lineage URL/SDK configuration without applying migrations, creating a database, emitting lineage, or contacting lineage transport.

## Schema and change control

- Canonical schema changes require a new Alembic migration; never rewrite an applied migration.
- Model, schema, migration, API, test, and canonical-document changes must land together when a contract changes.
- Preserve the existing fail-closed behavior, append-only lineage, deterministic execution, and human approval boundaries.

## Required qualification

Use the ForgeLineage SDK revision pinned in `.github/workflows/ci.yml` on `PYTHONPATH`, then run:

```bash
FORGEMATH_DATABASE_URL=sqlite:///./qualification.sqlite3 alembic upgrade head
PYTHONPATH=.ci/forge_lineage/sdk python -m pytest tests -q
python -m app.health_cli
FORGEMATH_DATABASE_URL=sqlite:///./qualification.sqlite3 python -m app.health_cli --readiness
bash doc/system/BUILD.sh
bash doc/system/validate_snapshots.sh
git diff --exit-code -- doc/MATSYSTEM.md
```

The Postgres invariant test is an explicit environment-dependent skip unless `FORGEMATH_POSTGRES_TEST_URL` is supplied. No other failure may be silently ignored.

## Pull requests and done

Keep PRs bounded. State compatibility impact, migration and test evidence, documentation-build evidence, health sample output, mathematical-semantics posture, deferred operational work, and rollback instructions. Do not merge or deploy without separate authority.

Work is done only when authored sources and generated docs agree, migrations apply to a clean disposable database, the complete configured suite passes except justified environment-dependent skips, health contracts pass, canonical lane and golden-vector outputs are unchanged, rebuilding docs is drift-free, and the PR records any external blockers.
